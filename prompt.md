Design and build a landing page for "Comate", an autonomous, agent-first desktop web browser equipped with an embedded intelligence layer ("The Browser with a Brain").

The aesthetic should feel sleek, futuristic, dark-mode-first, and ultra-premium (inspired by Linear.app, Arc.net, and Raycast). Use deep obsidian tones (#08090e, #0f111a), glassmorphism cards with subtle borders (rgba(255,255,255,0.08)), luminous cyan (#00ddff) and violet glows, and clean typography (Inter / Outfit).

### 1. Header / Navigation
- Left: Comate glowing icon + wordmark "Comate".
- Center links: Features, Autonomous Engine, Privacy & Vault, Changelog, Docs.
- Right: "Download" button (with OS auto-detection pill: e.g., "Download for Linux .deb" or "Windows .exe") and GitHub repo link with star badge.

### 2. Hero Section
- Tagline Badge: "✨ Comate v0.0.99 Beta is Live" (clickable to changelog).
- Main Headline: "Tell it what you want. It figures out how to do it."
- Subheadline: "The autonomous desktop browser that navigates, researches, and executes multi-step workflows on your behalf — with complete privacy and zero technical overhead."
- Call-to-Actions (CTAs):
  - Primary: Large glowing "Download Comate for [User OS]" button with platform dropdown (.deb, AppImage, .exe, portable, .dmg).
  - Secondary: "Watch 1-Min Demo" (modal / preview) or "Read the Docs".
- Hero Interactive Mockup:
  - High-fidelity browser chrome preview showing Comate in action:
  - Left: Chat / Agent Copilot stream with cognitive reasoning accordion ("Thinking...") and live action scratchpad ("Navigated to portal → Extracted table").
  - Right: Clean web viewport with an animated virtual glowing cursor and target pulse executing a workflow.

### 3. Social Proof / Core Axioms Bar
- Highlights:
  - ⚡ Sub-second Fact Grounding (Live search & zero hallucinations)
  - 🛡️ Zero-Knowledge Local Vault (AES-256 credential protection)
  - 🔄 Self-Healing TATF ReAct Loop (Auto-recovers from errors)
  - 📂 1-Click Browser Migration (Instant Chrome/Firefox bookmark import)

### 4. Core Features Grid (Bento Box Style)
- Card 1: Autonomous Browser Operator (@browser)
  - Description: Interacts with the live DOM, clicks, types, fills forms, and bypasses obstacles autonomously while keeping you in full control.
- Card 2: Grounded Real-Time Research (@research)
  - Description: Answers factual queries fast using real-time search, Wikipedia, and Markdown extraction without hallucinations.
- Card 3: Think-Apply-Test-Fix (TATF) Engine
  - Description: If a page errors or username collides, Comate diagnoses the issue and self-heals dynamically.
- Card 4: Local Credential Vault (L1/L2/L3 Permissions)
  - Description: Passwords never touch LLMs or third-party servers. Sensitive actions require explicit human handoff.
- Card 5: MarkItDown & Artifact System
  - Description: Converts PDFs, tables, and documents into clean GitHub-flavored markdown and local deliverables.

### 6. Interactive Workflow Showcase (Tabs / Interactive Carousel)
- Tab 1: "Autonomous Web Tasks" (e.g. "Create a repository on GitHub and download the release")
- Tab 2: "Deep Multi-Source Research" (e.g. "Compare GPU benchmark pricing across 4 vendors")
- Tab 3: "Document & Data Extraction" (e.g. "Convert complex tables on this page to CSV")

### 7. Download Matrix & System Requirements
- Platform tabs for Windows (x64 Setup & Portable), Linux (Debian/Ubuntu .deb & universal .AppImage), and macOS (.dmg).
- Displays version (v0.0.99), file size, release date, and direct SHA256 checksums.

### 8. Footer
- Links to GitHub repo, Release notes, Discord/Community, Privacy Policy, Terms, and Docs.
- Brand tagline: "Built by Cencera • The Browser with a Brain."
